Hosts

    Uses your own OpenSSH, so ProxyJump, keys and agents just work.
    Agents must request GPUs through Slurm (srun / sbatch --gres=gpu:N).

    Settings

    Uses Kimi Code's built-in desktop presentation and blends its header into the window title bar. Turn this off to show the plain web UI under a standard title bar, for example if a Kimi Code update changes how it looks.

    Kimi Code keeps running on each host after its window closes or the connection drops, so agents keep working. Use Stop Kimi Code on a host to shut it down.
